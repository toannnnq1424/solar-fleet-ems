# ADR-002: Vendor adapter architecture

Status: Accepted for implementation baseline, 2026-09-13.

## Context

Deye chỉ implementation đầu, không đặt field canonical theo vendor. SOLARMAN là platform.

## Decision

Tách telemetry/config/control/dispatch/provisioning/firmware. API catalog không phải device capability.

## Consequences

Mỗi adapter lưu version, transport, evidence, account scope và ngày xác minh.

Traceability: [Research report](../research-architecture-report.md), [source audit](../vendor-source-audit.md).
