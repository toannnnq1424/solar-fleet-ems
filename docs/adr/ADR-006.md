# ADR-006: Credential security

Status: Accepted for implementation baseline, 2026-09-13.

## Context

Loopback không phải trust boundary; frontend không nhận lại vendor secrets.

## Decision

Mã hóa secrets trong DB; master key ở OS keyring hoặc biến môi trường external, tách backup.

## Consequences

Scrypt password hash, session/CSRF/Host controls, exception không chứa payload secret.

Traceability: [Research report](../research-architecture-report.md), [source audit](../vendor-source-audit.md).
