# ADR-005: Command verification

Status: Accepted for implementation baseline, 2026-09-13.

## Context

HTTP success không chứng minh inverter nhận. Timeout có thể đã ghi, không retry tự động.

## Decision

Read-before-write, immutable diff, xác nhận, serialization, order tracking và readback mới.

## Consequences

Idempotency bền vững, audit từng trạng thái; không verified từ cached equality.
