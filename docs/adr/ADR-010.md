# ADR-010: Vendor-native escape hatch

Status: Accepted for implementation baseline, 2026-09-13.

## Context

UI đơn giản không được bỏ khả năng advanced; endpoint custom không cho phép bytes chưa rõ.

## Decision

Catalog giữ mọi control chính thức đã nghiên cứu, kèm điều kiện và lý do khóa.

## Consequences

Native/Raw vẫn đi cùng validation/confirmation/readback, không bypass safety.
