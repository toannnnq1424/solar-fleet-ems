# ADR-001: Local-first architecture

Status: Accepted for implementation baseline, 2026-09-13.

## Context

Office localhost không phải server routable cho site; phải có relay hoặc mạng riêng được cấu hình riêng.

## Decision

UI/controller bind 127.0.0.1 và luôn xác thực. Không tự mở inbound/tunnel. WAN transport tách khỏi UI.

## Consequences

Không publish website cho controller; kiểm thử Host, Origin và authentication.
