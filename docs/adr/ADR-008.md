# ADR-008: Time-series storage

Status: Accepted for implementation baseline, 2026-09-13.

## Context

Ước tính 500×5×30/5 = 15k points/s, không dùng SQLite vô hạn cho fleet.

## Decision

Pilot SQLite WAL giới hạn retention; tách repository để chuyển PostgreSQL partitioning khi scale.

## Consequences

Tách raw/1m/15m/day; đo capacity và backup/restore trước rollout.
