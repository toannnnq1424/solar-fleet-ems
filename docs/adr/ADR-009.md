# ADR-009: RBAC

Status: Accepted for implementation baseline, 2026-09-13.

## Context

Admin quản lý credentials không tự cấp engineering authorization cho lệnh raw.

## Decision

Viewer/Operator/Installer/Senior Engineer/Administrator với site scope; raw/grid là grant riêng.

## Consequences

Kiểm tra cả read/write/log/stream phía server; audit đăng nhập và thay quyền.

Traceability: [Research report](../research-architecture-report.md), [source audit](../vendor-source-audit.md).
