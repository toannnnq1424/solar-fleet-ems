# ADR-007: Site Agent architecture

Status: Accepted for implementation baseline, 2026-09-13.

## Context

Hai phía không inbound cần relay routable hoặc mạng riêng do đơn vị vận hành cấu hình.

## Decision

Outbox tại site, outbound mTLS, identity/certificate riêng, rotate/revoke, dedupe và timestamp gốc.

## Consequences

Chưa ship protocol driver/relay khi chưa có official maps và acceptance; không shared password.
