# ADR-003: Universal policy model

Status: Accepted for implementation baseline, 2026-09-13.

## Context

Tên tương tự không chứng minh tương đương; Reserve SOC không map BATT_LOW.

## Decision

Intent biên dịch qua capability + semantic mapping; exact/approximate/unsupported/manual là kết quả riêng.

## Consequences

Unknown fail closed, bulk trả riêng từng device và preview trước ghi.
